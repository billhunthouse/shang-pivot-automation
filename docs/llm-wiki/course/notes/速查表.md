## 订单状态

```text
PENDING_PAY → PENDING_SHIP → PENDING_RECEIVE → COMPLETED
PENDING_PAY → CLOSED（取消/15 分钟超时）
```

## 售后状态

```text
PENDING_AUDIT → REFUNDING → COMPLETED
PENDING_AUDIT → REJECTED
```

## 库存不变式

```text
physical >= locked >= 0
available = physical - locked
```
