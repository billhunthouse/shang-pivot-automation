# 练习题与答案

## 题 1：找到需求落点

**题**：`V2-FR-011` 涉及哪些页面和接口？

**答案要点**：

- 页面：`page:mall:/orders`、`page:mall:/orders/:id`；
- 接口：`GET /api/orders`、`GET /api/orders/{id}`、`GET /api/orders/{id}/logistics`、`POST /api/orders/{id}/cancel`、`POST /api/orders/{id}/confirm`；
- 证据：`data/requirements.json` + `data/pages.json`。

## 题 2：反查 Controller

**题**：`GET /api/products/{spuId}` 由谁处理、访问哪些表？

**答案要点**：

- `StorefrontController#productDetail`；
- `CatalogReadService`、`FavoriteBrowseService`；
- 表：`spu`、`sku`、`stock`、`review`、`category`、`favorite`、`browse_history`。

## 题 3：状态机

**题**：列出订单所有合法转移和入口。

**答案要点**：

- 创建 → `PENDING_PAY`：`POST /api/orders`；
- `PENDING_PAY` → `PENDING_SHIP`：`POST /api/payment/sandbox`；
- `PENDING_PAY` → `CLOSED`：取消/超时；
- `PENDING_SHIP` → `PENDING_RECEIVE`：`POST /admin/orders/{id}/ship`；
- `PENDING_RECEIVE` → `COMPLETED`：`POST /api/orders/{id}/confirm`。

## 题 4：库存并发

**题**：设计一个验证不超卖的用例。

**答案要点**：

- SKU 可用库存 = 1；
- 10 个并发请求同时下单；
- 期望 1 成功、9 失败；
- 校验 `physical >= locked >= 0`，无负库存。

## 题 5：售后审核

**题**：为什么测试不能断言 `REFUNDING`？

**答案要点**：

- 审核通过时同一事务先写 `REFUNDING` 再写 `COMPLETED`；
- 外部只能看到 `COMPLETED`；
- 应断言最终状态和副作用，而不是中间态。

## 题 6：评价边界

**题**：列出评价接口至少 8 条用例。

**答案要点**：

- 正常评价；
- 未完成订单；
- 重复评价；
- 评分 0/6/缺失；
- 内容超长；
- 图片超限；
- 未登录；
- 隐藏评价不出现在 C 端。

## 题 7：雪花 ID

**题**：为什么 `Number("2120852188811464706")` 会错？

**答案要点**：

- 超过 `Number.MAX_SAFE_INTEGER`；
- 双精度浮点无法精确表示；
- 末位被舍入为 `...4700`；
- 修复：全程字符串。

## 题 8：图谱查询

**题**：用 Cypher 查某页面调用的接口及落表。

**答案要点**：

```cypher
MATCH (p:Page {id:'page:mall:/product/:spuId'})-[:PAGE_CALLS_API]->(a:Api)
OPTIONAL MATCH (a)-[:ACCESSES_TABLE]->(t:Table)
RETURN p.label, a.label, collect(t.label);
```

## 题 9：RAG 评测

**题**：为“订单状态怎么流转”设计评测。

**答案要点**：

- `expected_ids`: `rule:order-state`；
- `must_contain`: `PENDING_PAY`、`PENDING_SHIP`、`CLOSED`；
- 指标：Hit@5、MRR、引用准确率。

## 题 10：影响分析

**题**：给商品增加“收藏夹分组”，输出五层影响。

**答案要点**：

| 层 | 影响 |
|---|---|
| 需求 | 新增需求 ID |
| 页面 | 收藏页、商品详情 |
| 接口 | 收藏列表/新增/移动分组 |
| 代码 | FavoriteBrowseService、Controller |
| 表 | `commerce.favorite` 增加 `group_id`，新增分组表 |
| 规则 | 分组归属、默认分组、删除分组 |
| 测试 | API 8 条 + UI 1 条 |
