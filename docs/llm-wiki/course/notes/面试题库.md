# 面试题库

## 架构

**1. 为什么用模块化单体？**  
单进程部署、事务简单、调试短；模块边界清晰，跨模块只走 API 契约，未来可拆。

**2. identity 和 commerce 怎么通信？**  
通过 `*-api` 接口，不直接依赖实现模块。

**3. 为什么管理端和 C 端 token 不通用？**  
两套登录体系和受众，避免越权；JWT 的 audience/claims 不同。

**4. 雪花 ID 有什么坑？**  
19 位超过 JS 安全整数，前端必须字符串；否则末位丢失导致 404。

**5. 为什么用 Flyway？**  
数据库版本化，环境一致，可回放。

## 测试

**6. 订单状态机怎么测？**  
合法转移、非法转移、重复操作、并发、库存/流水副作用。

**7. 库存怎么测并发？**  
多请求同时下单，验证 `physical >= locked >= 0`，不超卖。

**8. 售后通过后为什么没退款？**  
演示实现只改状态，不接真实支付；测试要断言这个边界。

**9. 接口测试最小断言集？**  
HTTP、业务码、关键字段、ID 字符串、DB 副作用、鉴权。

**10. UI 测试怎么避免脆弱？**  
`data-testid`、专用数据、少而关键、跨端闭环。

## 知识库

**11. LLM-wiki 的五层？**  
需求、页面、接口、Controller/Service、表。

**12. 怎么防 wiki 过期？**  
生成器 + 时间戳 + 真值顺序 + 变更后重跑。

**13. 图谱和调用链的区别？**  
图谱是静态结构，调用链是运行时；两者互补。

**14. RAG 召回不准怎么排查？**  
切片粒度、元数据、top-k、过滤、prompt 引用约束。

**15. 怎么评测 RAG？**  
20 条评测集，Hit@k、MRR、引用准确率、拒答率。

## 性能

**16. 100 VU 测试关注什么？**  
P95、错误率、吞吐、资源水位、慢 SQL、连接池、锁。

**17. 为什么平均值不够？**  
平均值掩盖长尾；P95/P99 才能反映用户体验。

**18. 发现 N+1 怎么确认？**  
开 SQL 日志/APM，看单请求查询次数和耗时。

## AI

**19. Agent 怎么评测？**  
正确性、引用、工具调用、延迟、成本、安全。

**20. AI 助手越权怎么防？**  
订单工具必须校验当前用户；未登录返回 `need_auth`；工具参数白名单。

## 答题结构

```text
结论 → 证据（文件/接口/表）→ 取舍 → 验证结果 → 如果重做会怎么改
```
