# 术语表

| 术语 | 一句话解释 |
|---|---|
| LLM-wiki | 面向 LLM 检索的项目知识库，强调结构、ID 和关系 |
| RAG | 先检索证据再生成答案 |
| chunk | 知识库的最小检索单元 |
| embedding | 把文本转成向量 |
| top-k | 召回前 k 条 |
| rerank | 对召回结果二次排序 |
| 知识图谱 | 节点 + 关系的结构化知识 |
| 一跳/两跳 | 沿关系走一层/两层 |
| traceability | 需求到页面、接口、代码、表的追溯 |
| 真值顺序 | 冲突时的优先级 |
| 雪花 ID | 分布式自增 ID，19 位 Long |
| 安全整数 | JS 能精确表示的最大整数 `2^53-1` |
| 模块化单体 | 单进程部署、模块边界清晰 |
| 聚合根 | 事务一致性边界内的主实体 |
| 状态机 | 状态与合法转移的集合 |
| 守卫 | 转移前必须满足的条件 |
| 幂等 | 重复执行结果一致 |
| 乐观锁 | 用版本号避免覆盖 |
| 悲观锁 | `SELECT ... FOR UPDATE` |
| N+1 | 循环里逐条查询 |
| 连接池 | 复用数据库连接 |
| P95 | 95% 请求的延迟上限 |
| 契约测试 | 验证接口字段/类型/错误码 |
| 数据工厂 | 构造测试数据的工具 |
| fixture | 测试前置/清理 |
| Allure | 测试报告框架 |
| BDD | 用自然语言描述行为 |
| MCP | 模型上下文协议，接外部工具 |
| Agent | 能规划并调用工具的 LLM 应用 |
| LangGraph | 用图编排 Agent 的框架 |
| 评测集 | 固定问题 + 标准答案 |
| Hit@k | 正确结果是否在前 k |
| MRR | 正确结果排名的倒数和均值 |
