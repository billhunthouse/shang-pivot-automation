# PRD-V2.1：商品评价商家回复

> 版本：V2.1（增量）  
> 日期：2026-11-12  
> 状态：已完成并通过 API/UI 自动化验证  
> 关联既有需求：V2-FR-015（评价）、V1-FR-025（评价管理）

## 1. 背景与目标

当前顾客可以在商品详情页看到评价，但商家无法对评价做公开回复。客服只能线下解释，评价区缺少“商家已关注/已处理”的可见反馈。

本版本新增：**管理端对单条评价发布一条商家回复，C 端商品详情页展示该回复**。  
不改变评价的星级、内容、可见性和审核状态。

## 2. 用户与场景

| 角色 | 场景 |
|---|---|
| 管理员 | 在「评价管理」找到评价，点击“回复”，填写回复内容并保存 |
| 顾客 | 在商品详情页看到商家回复，了解商家对评价的回应 |
| 运营/客服 | 通过回复解释物流、使用问题或售后建议 |

## 3. 功能需求

### FR-REV-REPLY-001 管理端回复评价

- 入口：管理端「评价管理」列表行内「回复」按钮。
- 弹窗展示评价摘要（商品/会员/星级/内容）。
- 输入商家回复，1–500 字，允许中文、英文、标点、换行。
- 保存后：
  - 该评价 `merchant_reply` 更新；
  - `replied_at` 记录当前时间；
  - 列表展示回复摘要；
  - 操作写入 `@OpLog(module="review", action="reply")`。
- 同一评价可重复回复，后一次覆盖前一次（修改回复）。
- 不改变评价 `status`、`rating`、`content`、`pics`。

### FR-REV-REPLY-002 C 端展示商家回复

- 商品详情页的 `reviewsPreview` 和 `/api/products/{spuId}/reviews` 返回 `merchantReply`、`repliedAt`。
- 有回复时，在评价内容下方展示「商家回复：…」。
- 无回复时不展示空块。
- 隐藏评价（`status=HIDDEN`）不进入 C 端评价列表，因此其回复也不展示。

### FR-REV-REPLY-003 权限与审计

- 仅管理端登录态可调用回复接口。
- 复用评价管理页权限（当前后端为认证级，接口级 RBAC 仍是已知缺口）。
- 操作写入操作日志，日志含评价 ID 和操作人。

## 4. 接口设计

### PUT `/admin/reviews/{id}/reply`

请求：

```json
{ "reply": "感谢您的反馈，物流问题我们已记录并优化。" }
```

成功：

```json
{ "code": 0, "msg": "success", "data": null }
```

失败：

| 场景 | HTTP | code | msg |
|---|---:|---:|---|
| 未登录 | 401 | 40100 | 未认证 |
| 评价不存在 | 200 | 40400 | 资源不存在 |
| 回复为空 | 200 | 40000 | 回复内容不能为空 |
| 回复超过 500 字 | 200 | 40000 | 回复不能超过 500 字 |

### 读接口变更

- `GET /admin/reviews`：每条记录新增 `merchantReply`、`repliedAt`。
- `GET /api/products/{spuId}/reviews`：Review 实体新增字段。
- `GET /api/products/{spuId}`：`reviewsPreview[]` 新增字段。

## 5. 数据模型

迁移 `V22__review_merchant_reply.sql`：

| 列 | 类型 | 可空 | 说明 |
|---|---|---|---|
| `merchant_reply` | `TEXT` | 是 | 商家回复内容 |
| `replied_at` | `TIMESTAMPTZ` | 是 | 最近回复时间 |

## 6. UI 交互

### 管理端「评价管理」

- 新增「商家回复」列，最多展示 30 字，超出省略。
- 操作列新增「回复 / 修改回复」按钮。
- 弹窗：评价摘要 + textarea + 字数提示 + 保存/取消。
- 空内容/超长：弹窗内 `.error-text` 内联提示，不使用 toast 替代。
- 保存成功：关闭弹窗、刷新列表、`ElMessage.success("回复已保存")`。

### C 端商品详情

- 评价内容下方显示商家回复块：
  ```text
  商家回复：感谢您的反馈...
  ```
- 样式与评价卡片区分，但不抢主内容。

## 7. 非功能与验收

- 回复内容输出必须转义，防 XSS。
- 500 字边界：500 通过、501 拒绝。
- 回复只影响目标评价，不改变其他评价/评分/状态。
- 管理端列表和 C 端详情在保存后刷新可见。
- 操作日志可追溯。
- 不引入新表；只加两列，兼容旧数据（NULL 表示未回复）。
