## 4. 执行命令

```bash
cd api_testcases

RUN_UI=1 \
ADMIN_BASE_URL=http://127.0.0.1:8086/admin \
MALL_BASE_URL=http://127.0.0.1:8086 \
ADMIN_UI_URL=http://127.0.0.1:5173 \
MALL_UI_URL=http://127.0.0.1:5174 \
ADMIN_TEST_ACCOUNT=admin \
ADMIN_TEST_PASSWORD='<local password>' \
UI_HEADLESS=true \
python3 -m pytest tests/functional/test_review_reply.py tests/ui/test_review_reply_ui.py \
  -q --alluredir=artifacts/allure-review --clean-alluredir

bash scripts/allure_report.sh \
  --results artifacts/allure-review \
  --report artifacts/allure-review-report
```

## 6. 覆盖边界与缺口

已覆盖：

- 回复成功、C 端列表与详情双入口展示
- 未登录、空白、超长、404
- 重复回复覆盖
- 隐藏评价不可见

尚未覆盖（建议下一轮）：

- 500 字整边界（当前覆盖 501 拒绝）
- 含 HTML/脚本的 XSS 内容
- 回复权限（低权限管理员，当前后端无接口级 RBAC）
- 操作日志内容核验
- 并发回复/并发隐藏与恢复
- 回复历史/审计（当前只保留最新一条）
- 特殊字符、emoji、换行、纯空白 Unicode
